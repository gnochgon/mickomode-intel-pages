mickomode-intel

A personal analytics tool. Not a public service.

mickomode-intel is a private tool that the creator of the mickomode YouTube channel runs on his own computer to read his own channel's statistics. It has exactly one user: the channel owner.

What it does

  • Signs in with Google using read-only access to one YouTube channel: its videos and their statistics, YouTube Analytics reports, and YouTube's daily reach reports (impressions and click-through rate).
  • Stores that data on the owner's own computer and shows it in a local dashboard to help plan content.
  • Never posts, edits, deletes or manages anything on YouTube.

There is no sign-up and no way for anyone else to use it. It uses YouTube API Services. The privacy policy lists exactly what is accessed and how to revoke access.
